# 股票行情监测

美股、A 股和国内期货主力连续分开监测。每边有自选、热门交易、板块买点。日线上的买入区、卖出区和支撑是交易计划，不是涨跌预测，也不是投资建议。

## 使用

1. 双击 `启动.bat`。
2. 浏览器打开 http://127.0.0.1:8765 。
3. 关掉黑色窗口就会停止。

自选和行情缓存写在本目录的 `data` 文件夹。如果 8765 已被占用，会改用 8766，再占用就继续加 1，浏览器打开实际用到的端口。

## 项目介绍

- 自选只计算添加的代码，最多 40 只。
- 热门交易按成交额取前 20。期货用上一交易日的成交额。
- 板块买点从股票指数成分股里筛出当前可以分批买入的。A 股用中证红利、中证 A500、中证 500；美股用标普 500、纳斯达克 100。期货按品种分组，只留可以分批买入的主力合约。
- 日线保留最近一年。趋势看 EMA20、EMA50、EMA200。支撑是最近确认的摆动低点，现价跌破就先别买。
- 详情里可以输入自定义价格，看这个价格落在哪一档。A 股另外有财务评分，美股和期货没有这一项。
- 期货是交易所主力连续。夜盘成交算进下一根日线，不画盘中分时，也不包含保证金。
